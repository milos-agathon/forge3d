# VACUUM raster sampling inventory

The comparison revision is `5508e16d` on `origin/main`. Paths below are relative to the repository root. “Missing” means a declared marker in the stored sample type, an explicit invalid mask bit, or a nonfinite floating-point value. A finite number, including a negative elevation or zero, is data unless the source declares it missing.

For a continuous filter, discard missing taps, sum the remaining weighted values, and divide by the remaining weight. The minimum is half the footprint's weight, including equality, following the COG coverage convention. At a raster border use the operation's existing boundary convention. A derivative needs the centre and at least one distinct valid node on its axis. Use a central difference with two neighbours and a one-sided difference with one. An analysis value with no usable stencil is missing. A renderer can use a neutral material normal where the direction is indeterminate. Nearest and categorical filters retain their discrete semantics.

Height and colour averages and reported min/max ranges apply the support rule at each level. Power-of-two padding lies outside the logical footprint. Ray traversal uses a separate conservative hierarchy. A node encloses every valid descendant that could be hit. Empty nodes have inverted bounds. A leaf still checks the half-weight surface coverage. Rejecting a sparse bounding node on its average coverage would hide valid intersections.
